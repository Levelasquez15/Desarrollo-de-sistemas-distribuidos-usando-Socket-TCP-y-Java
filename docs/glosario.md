# Glosario de Términos

- **Socket:** Es un punto final (endpoint) de una comunicación bidireccional entre dos programas a través de una red. Está ligado a un número de puerto para que la capa TCP pueda identificar a la aplicación a la cual van destinados los datos.
- **TCP (Transmission Control Protocol):** Protocolo de red orientado a conexión que garantiza que los datos sean entregados en su destino sin errores y en el mismo orden en que se transmitieron.
- **Servidor:** Instancia de software que espera (escucha) por solicitudes de conexión provenientes de otros programas en la red para ofrecerles un servicio (en este caso, el cálculo del IMC).
- **Cliente:** Programa o instancia de software que inicia una conexión hacia un servidor consumiendo un servicio expuesto por este.
- **IP (Internet Protocol):** Dirección lógica que identifica a un dispositivo en una red.
- **Puerto (Port):** Número lógico (de 16 bits) asociado a una dirección IP que identifica una aplicación o proceso específico en un dispositivo. En el proyecto se usa el `9007` como ejemplo.
- **IMC (Índice de Masa Corporal):** Métrica que asocia la masa y la talla de un individuo. Se calcula con la fórmula matemática: `Peso / (Altura * Altura)`.
- **Hilo (Thread):** Es una unidad básica de utilización de la CPU. Permite a una aplicación realizar múltiples tareas al mismo tiempo (Concurrencia).
- **Swing:** Biblioteca de Java utilizada para crear interfaces gráficas de usuario (GUI) para programas de escritorio.
- **Stream de Datos (`DataInputStream` / `DataOutputStream`):** Clases en Java que permiten a una aplicación leer/escribir tipos de datos primitivos de Java de una manera portable e independiente de la máquina subyacente.
